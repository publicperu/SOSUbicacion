SOS Ubicación - cómo obtener el APK

OPCIÓN A (Android Studio)
1. Descomprime y abre la carpeta con Android Studio.
2. Espera a que termine "Gradle Sync".
3. Menú Build > Build App Bundle(s) / APK(s) > Build APK(s).
4. El archivo queda en app/build/outputs/apk/debug/app-debug.apk

OPCIÓN B (sin instalar nada, con GitHub)
1. Crea un repositorio en github.com y sube todo el contenido (incluida la carpeta .github).
2. Ve a la pestaña Actions > "Build APK" > espera ~3 min.
3. Descarga el artefacto "SOSUbicacion-apk" (contiene app-debug.apk).

Instalar: pasa el APK al teléfono y permite "instalar apps de orígenes desconocidos".
